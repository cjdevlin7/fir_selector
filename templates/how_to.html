How to use FIR Selector

Pick a color, select FIRs, and export a full-resolution PNG.

  1. 1. Pick a color

    Choose a swatch from the palette, or use the custom color picker. Whichever is highlighted as the "active color" gets applied to the next FIR you select.

  2. 2. Set a background

    Pick Dark, Light, or a custom color. It updates both the live map preview and the exported image. Check "Include Aireon Logo" to add the logo to the export — white on dark backgrounds, dark on light ones — shown as a live preview in the map's corner.

  3. 3. Select FIRs

    Click directly on a FIR's outline on the map, or search by name or ICAO id in the sidebar list and click a result — either way selects it in the active color and adds it to the selection. Clicking an already-selected FIR again removes it.

  4. 4. Apply a list

    Use the "Apply a list…" dropdown above the search box to select every FIR in a named set (like Customer FIRs) at once, in the active color.

  5. 5. Save or load your own list

    Click "Save as list…" to download your current selection and its color as a .json file. Load one back later via "Apply a list" → "Load list from file…", or by dragging the file onto the map — a dialog confirms the FIR count and lets you override the color before applying. Loading always adds to your current selection rather than replacing it. Sharing a list with someone else is just sending them the file.

  6. 6. Adjust as you go

    Change the active color any time before selecting more FIRs. Use "Select filtered" to select every FIR currently matching your search, the × next to an entry to remove just that one, or "Clear all" to start over.

  7. 7. Export

    Click "Export PNG" to download a full-resolution image of your current selection, styled to match the background you picked. Each export gets a unique, timestamped filename.
